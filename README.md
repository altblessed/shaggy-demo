# Shaggy — design demo

A static grooming salon design demonstration. This is not the salon's official website.

HTML, CSS and JavaScript; no build step, server or paid dependencies required.
The contact information and photographs come from the salon's public Yandex Maps listing:
https://yandex.ru/maps/org/shaggy/4322357769/

This repository does not grant a license to third-party photographs or brand materials.

## GitHub Pages

Settings > Pages > Build and deployment > Deploy from a branch > main > / (root) > Save.
The .nojekyll file disables the Jekyll processing step.
